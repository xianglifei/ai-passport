# Kaka — an AI Passport virtual pet cat

An offline virtual-pet game for a young child: care for an orange tabby cat
named **Kaka** with just three physical keys (UP / DOWN / OK). Bright pixel
art — every sprite is generated deterministically by a script; the meow
voice layer is real cat recordings (CC0 public domain, see
assets/snd/README.md) and everything else is synthesized in code.
No licensed assets, no network.

Branch: `feature/kaka-pet` (based on upstream `FoloToy/ai-passport` main).

## How to play

First boot: pick a name for your kitten from six presets (UP/DOWN to cycle, OK to confirm).

| Key | Context | Action |
| --- | --- | --- |
| UP / DOWN short | Home | Switch activity: feed / brush / sunbathe / walk |
| UP / DOWN short | In activity | A little poke: Kaka squints and wiggles (no dead keys) |
| OK short | Home | Start the selected activity |
| OK short | In activity | Interact: another fish / another stroke / wake early / pounce |
| OK long | Anywhere | Bedtime ritual: night screen + lullaby; any key wakes Kaka |
| UP long | Anywhere | Parent control: volume cycle loud / medium / mute (persisted) |
| DOWN long | Home | Memory album: lifetime totals + how-to-play card; any key exits |

- **Feed**: three fish per meal; when full Kaka politely refuses and stays in
  the scene (shy heart); after three refusals it yawns and wraps up gently.
- **Brush**: one stroke per press; five strokes make the coat shine.
- **Sunbathe**: 8 s of warm nap (butterfly, Zzz); press OK to wake early.
- **Walk**: 12 s side-scrolling street with parallax; houses, sky and trees
  are re-rolled every walk; press OK to pounce.
- **Growth**: cumulative care (fish + strokes + naps + walks) grows the cat
  through kitten → teen → adult — smaller sprite, higher meow, collar badge
  at adulthood, "grew up!" moment on stage-up.
- **Milestones**: every 10th fish/stroke/nap/walk triggers a mini celebration;
  the memory album (DOWN long) shows the lifetime totals.
- **Status dashboard**: the top half of the memory album shows the three
  live stats (fullness / cleanliness / happiness) as icon bars; anything
  below the care threshold (40) turns red — what the cat needs, at a
  glance. The home screen stays clean and leaves just-in-time hints to
  the bubble.
- **Ambient life**: left alone on the home screen, Kaka strolls, pounces at a
  butterfly, or stares at its bowl when hungry.
- **Reunion**: re-powering after real absence applies a fixed 6-hour decay
  (no RTC battery; the firmware does not pretend to know the gap) — and if
  the stats dropped noticeably, Kaka greets you back with hearts and
  "missed you".
- **Voice**: the microphone listens while idle — a clap or a shout gets a
  meow in reply (echo-guarded and rate-limited; self-disables if the mic
  errors).
- **Gentle nurturing**: fullness / cleanliness / happiness decay slowly and
  are floored at 15 — Kaka never gets sick, at most it misses you; a bubble
  shows what it wants.
- **Sound**: the "voice" layer (greeting, happy, sweet, hungry, sleepy,
  trill, kitten squeak) uses **real cat meow samples** (CC0; pitch-shifted
  up while a kitten); scene effects (munch, purr, bell, sparkle, birds,
  wind, lullaby…) are procedural; Kaka also meows randomly while idle.
- **Power**: backlight dims to 30% after 60 s idle, night screen after 5 min;
  any key restores.

## Layout

```
main/pet_model.c    pure logic: stats/decay/activity FSM (host-testable)
main/pet_store.c    save serialization (host-testable); pet_nvs.c = NVS glue
main/pet_ui.c       home/night screens, particles, celebration;
main/pet_scenes.c   the four activity scenes
main/pet_audio.c    two-layer sound system (sampled meows + procedural effects)
main/snd/           real meow samples (16k mono PCM, generated by assets/snd/gen_sounds.sh)
main/pet_art.c      pixel assets (LVGL I4, generated by assets/cat/gen_assets.py)
assets/fonts/       Chinese font subset (Noto Sans SC OFL 1.1, gen_app_fonts.sh)
assets/snd/         meow source WAVs + generation script + license notes
tests/test_pet_*.c  host logic tests (wired into tools/validate.sh --static)
```

## Build & validate

Uses the repository gate (requires ESP-IDF 5.5.3):

```bash
./tools/validate.sh --static    # repo checks + host tests
./tools/validate.sh --firmware  # firmware build + merged-image validation
```

Tweak the cat's look: `python3 assets/cat/gen_assets.py` (use `--png-only`
while iterating on the preview). Change Chinese copy: update the SYMS list in
`assets/fonts/gen_app_fonts.sh` and `PET_GLYPH_SET` in `main/pet_font.h`,
then regenerate.
