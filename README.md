# Kaka — an AI Passport virtual pet cat

An offline virtual-pet game for a young child: care for an orange tabby cat
named **Kaka** with just three physical keys (UP / DOWN / OK). Bright pixel
art — every sprite is generated deterministically by a script — and every
sound is synthesized in code. No licensed assets, no network.

Branch: `feature/kaka-pet` (based on upstream `FoloToy/ai-passport` main).

## How to play

| Key | Context | Action |
| --- | --- | --- |
| UP / DOWN short | Home | Switch activity: feed / brush / sunbathe / walk |
| OK short | Home | Start the selected activity |
| OK short | In activity | Interact: another fish / another stroke / wake early / pounce |
| OK long | Anywhere | Bedtime ritual: night screen + lullaby; any key wakes Kaka |
| UP long | Anywhere | Parent control: mute on / off (persisted) |

- **Feed**: three fish per meal; when full Kaka politely refuses (sniffs,
  nudges the bowl, one shy heart).
- **Brush**: one stroke per press; five strokes make the coat shine.
- **Sunbathe**: 8 s of warm nap (butterfly, Zzz); press OK to wake early.
- **Walk**: 12 s side-scrolling street with parallax; press OK to pounce.
- **Gentle nurturing**: fullness / cleanliness / happiness decay slowly and
  are floored at 15 — Kaka never gets sick, at most it misses you; a bubble
  shows what it wants. Re-powering applies a fixed 6-hour-equivalent decay
  (no RTC battery; the firmware does not pretend to know the gap).
- **Sound**: a "voice" layer of expressive meows (greeting, happy, sweet,
  hungry, sleepy, trill…) plus scene effects (munch, purr, bell, sparkle,
  birds, wind, lullaby…) — all procedural; Kaka also meows randomly while
  idle.
- **Power**: backlight dims to 30% after 60 s idle, night screen after 5 min;
  any key restores.

## Layout

```
main/pet_model.c    pure logic: stats/decay/activity FSM (host-testable)
main/pet_store.c    save serialization (host-testable); pet_nvs.c = NVS glue
main/pet_ui.c       home/night screens, particles, celebration;
main/pet_scenes.c   the four activity scenes
main/pet_audio.c    two-layer sound system (meow voice + effects, procedural)
main/pet_art.c      pixel assets (LVGL I4, generated by assets/cat/gen_assets.py)
assets/fonts/       Chinese font subset (Noto Sans SC OFL 1.1, gen_app_fonts.sh)
tests/test_pet_*.c  host logic tests (wired into tools/validate.sh --static)
```

## Build & validate

Uses the repository gate (requires ESP-IDF 5.5.3):

```bash
./tools/validate.sh --static    # repo checks + host tests
./tools/validate.sh --firmware  # firmware build + merged-image validation
```

Tweak the cat's look: `python3 assets/cat/gen_assets.py` (use `--png-only`
while iterating on the preview). Change Chinese copy: update the SYMS list in
`assets/fonts/gen_app_fonts.sh` and `PET_GLYPH_SET` in `main/pet_font.h`,
then regenerate.
