# 卡卡 Kaka —— AI Passport 电子宠物猫

给 5 岁孩子的离线电子宠物游戏:孩子用 上 / 下 / 确认 三键照顾一只橘猫
"卡卡"。明快像素风,美术由脚本确定性生成;喵声为真实录音采样(CC0
公有领域,来源见 assets/snd/README.md),其余声音由代码合成。
零版权负担、零联网。

分支:`feature/kaka-pet`(基于上游 `FoloToy/ai-passport` main)。

## 玩法

首次开机:从 6 个预设名里给小猫起名(上/下 换,确认 定)。

| 按键 | 语境 | 行为 |
| --- | --- | --- |
| 上 / 下 短按 | 主界面 | 切换活动:喂食 / 刷毛 / 晒太阳 / 散步 |
| 上 / 下 短按 | 活动中 | 戳一戳:眯眼 + 小摆动(场景内没有死键) |
| 确认 短按 | 主界面 | 开始选中的活动 |
| 确认 短按 | 活动中 | 场景内互动:再吃一条鱼 / 再刷一下 / 提前唤醒 / 跳跃扑蝶 |
| 确认 长按 | 任意 | 睡前仪式:夜晚屏 + 摇篮曲,任意键唤醒 |
| 上 长按 | 任意 | 家长控制:音量循环 高 / 中 / 静音(持久化) |
| 下 长按 | 主界面 | 回忆相册:累计成就 + 玩法说明,任意键退出 |

- **喂食**:三条鱼一组;吃饱后卡卡礼貌拒喂并**留在场景里**(害羞爱心),
  连续三次拒喂才打个哈欠温柔收尾。
- **刷毛**:每按一下刷一下,连刷五下毛发发亮收尾。
- **晒太阳**:8 秒暖阳小憩(蝴蝶绕飞、Zzz),可按确认提前唤醒。
- **散步**:12 秒横向卷轴街道(视差滚动);房子、天空、树每次随机换装,
  按确认扑跳。
- **成长**:累计照顾量(鱼 + 刷 + 晒 + 走)推动 幼猫 → 少年 → 成年——
  个头变大、叫声变沉、成年戴上项圈,跨阶时播"长大了!"。
- **里程碑**:吃鱼 / 刷毛 / 晒太阳 / 散步每满 10 次小庆祝一次;
  下 长按的回忆相册里能看到全部累计。
- **状态仪表盘**:回忆相册上半页是当前状态三条进度条(饱食/干净/
  心情),低于照顾线(40)的项变红 —— 什么时候该喂、该刷、该遛,
  一眼可读;主界面保持纯净,只留给气泡做即时提醒。
- **环境生命**:主界面放空一会儿,卡卡会自己踱步、扑蝴蝶,
  饿了就蹲过去盯着碗。
- **重逢**:重新上电统一按 6 小时等效衰减补进度(设备无 RTC 电池,
  不假装知道关了多久);掉状态明显时,开机是一场重逢——爱心雨
  加一句"想你了"。
- **声音回应**:空闲时麦克风听一耳朵,拍手或喊一声,卡卡会喵一声回你
  (带回声抑制与频控;麦克风异常则本次上电自动停用)。
- **轻养成**:饱食 / 干净 / 心情三项,缓慢下降且**下限 15**——卡卡永远
  不会生病,最低只是想你;头顶气泡提示想要什么。
- **声音**:喵声"配音"(问候 / 开心 / 撒娇 / 饿了 / 困倦 / 颤音 / 小奶猫)
  为**真实猫叫采样**(CC0,幼猫阶段自动升调播放);效果层(咀嚼、呼噜、
  铃铛、闪光、鸟鸣、风、摇篮曲…)由配方合成器生成;空闲时卡卡会随机喵。
- **功耗**:60 秒无操作背光降到 30%,5 分钟进夜晚屏,任意键恢复。

## 结构

```
main/pet_model.c    纯逻辑:状态/衰减/活动 FSM(host 可测)
main/pet_store.c    存档序列化(host 可测);main/pet_nvs.c 为 NVS 胶水
main/pet_ui.c       主界面/夜晚屏/粒子/庆祝;main/pet_scenes.c 四个活动场景
main/pet_audio.c    两层声音系统(喵声采样 + 过程式音效)
main/snd/           真实猫叫采样(16k 单声道 PCM,由 assets/snd/gen_sounds.sh 生成)
main/pet_art.c      像素资产(LVGL I4,由 assets/cat/gen_assets.py 生成)
assets/fonts/       中文字体子集(Noto Sans SC OFL 1.1,gen_app_fonts.sh)
assets/snd/         声音采样源 WAV + 生成脚本 + 来源许可证说明
tests/test_pet_*.c  host 逻辑测试(挂进 tools/validate.sh --static)
```

## 构建与验证

沿用仓库统一门禁(需 ESP-IDF 5.5.3):

```bash
./tools/validate.sh --static    # 仓库检查 + host 测试
./tools/validate.sh --firmware  # 固件构建 + 合并镜像校验
```

改像素形象:`python3 assets/cat/gen_assets.py`(先 `--png-only` 调预览);
改中文文案:同步更新 `assets/fonts/gen_app_fonts.sh` 的 SYMS 与
`main/pet_font.h` 的 `PET_GLYPH_SET` 后重新生成。
